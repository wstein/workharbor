## Delivered adapter

The production handler calls `Client.PreparePromotion`; it does not restage,
rebuild, infer a source directory or grant new fingerprint trust. Exact primary
selection and receipt/source/config verification remain with the merged library.
There is no bare promote alias and no `--trust` or `--source` flag.

Apply requires explicit `--volumes` and `--force`, then confirmation or `--yes`.
JSON and nonterminal calls never prompt. `--yes` supplies neither deletion flag.
Dry-run without either deletion flag returns the library preview and closes
preparation without Apply; dry-run with volumes alone refuses 70. Invalid selectors
or unsupported flags refuse 64 with their reasons before preparation.

The human preview states that primary replacement ends shell panes and other
exec sessions, states that the original primary home is never a cleanup target,
and permits trusted container hooks to write the original workspace. Interactive
mutation confirmation acknowledges the existing pause-writers condition. The
adapter supplies the existing consent fields; it adds no backup or safety layer.

Partial results retain the library's recovery identity, inventories, code,
message and remediation in the schema-version-1 canonical-command envelope.
The result schema reuses the accepted closed lifecycle shape. No remote operation
ID is manufactured. The existing library owns rollback, verified-image use,
original-home preservation and candidate cleanup.

## Reproduce

Run from the repository root with `umask 022`:

```sh
go -C apps/whr test ./internal/commands -run '^TestLocalPromote' -count=1
go -C apps/whr test ./internal/commands
go -C apps/whr vet ./...
python3 -B scripts/check_repo.py
python3 -B -m unittest discover -s tests
git diff --check
```

`TestLocalPromoteRegistryDispatch` records the running missing-command RED in
commit `5b1326cf`. The test-only adapter expectations precede implementation in
`187e6fb2`. Its schema cases also failed before the promote schema dispatch was
added. The consent table checks the refusal reason and zero prepare/apply calls
for unconsented invocations; preview and apply paths assert exact consent and
close counts. Interactive tests exercise full, declined, absent, unterminated
and oversized answers, with ANSI decoration disabled for hostile-metadata checks.
The partial-result test checks the exact library error, remediation, recovery ID,
effects and recovery instructions with their volume targets.
The closed-schema test rejects extra/missing fields and fictional operation IDs.
All six new test identities are required in the CI acceptance manifest.

These are hermetic adapter tests. Actual macOS+OrbStack/Linux Docker promotion,
primary-home data retention and recovery observations remain owner-host evidence
in the final runbook package. This record does not claim T038/T034 acceptance,
