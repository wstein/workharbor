## Contract and source

- `apps/whr/internal/resources/resources.go` is a pure parsing and resolution
  library: no I/O, clock, mutable global state or command integration. CPU values
  are integer thousandths, memory values integer bytes, bounded by `2^63-1`.
  CPU grammar permits at most three fractional digits; memory requires whole
  MiB or GiB with case-sensitive units. Canonical formatting round-trips.
- `contracts/cli/resources-vectors.json` contains 69 CPU cases (14 accepted,
  55 rejected), 67 memory cases (11 accepted, 56 rejected), 17 resolution cases
  and two equivalence sets. Across both parsing sections all specified rejection
  classes are exercised: empty, sign, nonfinite, exponent, syntax,
  excess_precision, missing_unit, bad_unit, not_positive and overflow.
- The file supplies ASCII grammar, integer units and limits, classification
  precedence, canonical expectations, error classes, flag/profile inputs,
  origins, unattended needs-human and interactive prompt expectations. A future
  Elixir implementation can consume the same JSON with integer-preserving
  decoding. The ordered nonfinite/exponent descriptions now agree with the
  existing classification notes, vector cases and parser. Only those two prose
  entries changed; case data and acceptance/rejection behavior are unchanged.
- `Resolve` selects each field independently from explicit input, then the host
  profile, otherwise leaves it unresolved. Invalid explicit input never falls
  back. Omission never means unlimited; `Effective` refuses incomplete results.
  Equivalent CPU spellings and `1GiB`/`1024MiB` have equal canonical identity.
