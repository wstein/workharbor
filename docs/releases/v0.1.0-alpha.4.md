**WorkHarbor v0.1.0-alpha.4** (pre-release): an alpha with a clone-free installer, built for macOS on Apple silicon.

- **Highlights:** `install-release.sh` is now a release asset and runs without a clone and without `gh` (#459); every release needs a summary file under `docs/releases/`, which this file is (#443); `make install` supports `DESTDIR` for staged installs and refuses symlinks below it (#473); the manual documents uninstalling `whr` (#471); SECURITY.md states the vulnerability response process and which alpha gets fixes (#470).
- **You can now:** install a release from the downloaded script and `checksums.txt` alone, verifying the script's attestation first when `gh` is installed.
- **Known limits:** unverified: this is the first release that ships `install-release.sh`, and its asset upload and attestation have not run in a release yet. Issues #342 (initiation gate) and #364 (per-client API credentials) are not part of this release.
- **Verify provenance:** `shasum -a 256 -c checksums.txt`; provenance is `whr_v0.1.0-alpha.4.intoto.jsonl`, checked with `gh attestation verify`.

## Install

macOS on Apple silicon; needs only `curl`, `shasum`, `tar` and `install`. Replace `v0.1.0-alpha.4` and run as the administrator; the prefix is `/opt/whr` (add another path as a second argument).

```bash
tag=v0.1.0-alpha.4; base=https://github.com/wstein/workharbor/releases/download/$tag
curl -fsSLO "$base/install-release.sh" -O "$base/checksums.txt" &&
shasum -a 256 -c checksums.txt --ignore-missing   # install-release.sh: OK
```

With the GitHub CLI (`gh`) installed, verify the script itself next, because the installer runs as root and its own attestation check proves nothing if the script was swapped:

```bash
commit=$(gh api repos/wstein/workharbor/commits/refs/tags/$tag --jq .sha) &&
gh attestation verify install-release.sh --repo wstein/workharbor \
  --signer-workflow wstein/workharbor/.github/workflows/release.yml \
  --source-ref refs/tags/$tag --source-digest "$commit" \
  --deny-self-hosted-runners
```

Then run the installer as the administrator:

```bash
sudo bash install-release.sh "$tag"
```

The script then also verifies the archives' attestation; without `gh` only the checksums are checked, which proves the download is intact, not who built it. The `workharbor` user must not be able to write the prefix. Full guide: [Install, upgrade and release](https://wstein.github.io/workharbor/docs/manual/install-upgrade-release/).
